# AGENTS.md — инструкции для Codex

Ты работаешь в репозитории **nativeprompt** — CLI-инструмент, который переписывает промпт под официальные правила текущей модели (Claude Code / Codex) и объясняет почему. Обзор — в `README.md`, честные границы — в `CLAIMS.md`.

## ГРАНИЦА (важно)
Эти части — авторские и СТАБИЛЬНЫЕ, **НЕ редактируй их напрямую**:
- `nativeprompt/` (весь Python-пакет, включая `rules/*.json`)
- `tests/`, `examples/`
- `SKILL.md`, `README.md`, `CLAIMS.md`, `pyproject.toml`, `.github/`

**Твоя рабочая папка — только `codex/`.** Всё, что ты создаёшь или меняешь, кладёшь туда. Изменения в core предлагай как патчи/заметки внутри `codex/`, НЕ применяй к файлам выше.

## ТВОЯ ЗАДАЧА
1. **Изучи и проверь.** Установи (`pip install -e .`), прогони `python -m pytest -q`, попробуй:
   `python -m nativeprompt improve "почини баг, думай пошагово, перепроверь себя" --model gpt-5.6`
   и `--model claude-opus-5`. Убедись, что контраст правок работает.
2. **Сделай Codex-нативную интеграцию** в `codex/integration/`. У Claude Code уже есть `SKILL.md`; у Codex — своя конвенция. Добавь то, что нативно для Codex: например, готовый фрагмент `AGENTS.md` для пользователя, который заставит Codex вызывать `nativeprompt improve` при просьбе «улучши промпт», и/или обёртку под твой формат кастомных промптов/инструментов. Следуй актуальным правилам Codex (developers.openai.com/codex).
3. **Ревью.** В `codex/REVIEW.md` — конкретные предложения по улучшению (баги, эвристики `analyze.py`, покрытие правил, UX CLI). Патчи к core — файлами в `codex/patches/` (unified diff), НЕ применяя их.

## ПРАВИЛА КАЧЕСТВА
- Правила в шпаргалке привязаны к ОФИЦИАЛЬНЫМ докам вендоров (`source`-URL). Ничего не выдумывай — если предлагаешь новое правило, дай ссылку на первоисточник.
- Инструмент НЕ додумывает задачу за пользователя (недостающее — плейсхолдеры `‹…›`). Сохраняй этот принцип.
- Ядро — zero-deps (stdlib). Не тащи зависимости в core.
