# Примеры «сырых» промптов для демо

Прогоняйте так:

```bash
python3 -m nativeprompt improve "<промпт отсюда>" --model claude-opus-5
python3 -m nativeprompt improve "<промпт отсюда>" --model gpt-5.6
```

### 1. Классика «как привыкли» (много правок на обеих моделях, но разных)
> Не мог бы ты пожалуйста ОБЯЗАТЕЛЬНО починить баг в логине, думай пошагово и обязательно перепроверь себя. Покажи только самое важное.

### 2. Нет контекста и проверки
> Напиши функцию валидации email.

### 3. Форма задачи = goal (советует /goal)
> Мигрируй модуль оплаты на новый API, пока все тесты не пройдут.

### 4. Форма задачи = workflow (советует dynamic workflow / делегирование)
> Проверь все файлы маршрутов на пропущенную авторизацию, по агенту на файл.

### 5. Форма задачи = planning (советует plan mode / /plan)
> Спроектируй, как лучше добавить OAuth, какой подход выбрать, затрагивается несколько файлов.

### 6. Противоречие (ловится для Codex)
> Ответь кратко, но максимально подробно распиши каждый шаг рефакторинга @src/api.py.

### 7. Хорошо оформленный промпт (правок почти нет — так и надо)
> Добавь тест в @src/foo.py на случай разлогина; без моков. Прогони pytest и почини, пока не пройдёт. Верни только изменённый файл.
